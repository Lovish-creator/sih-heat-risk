## Notes on Data Quality Labels

- `official_datameet`: Sourced directly from verified open-license government municipal delimitation shapefiles via DataMeet.
- `illustrative_prototype`: Synthetic/stylized municipal delimitation boundaries or population attributes used for interface and algorithm demonstration.
- `estimated`: Demographic attributes computed using state/district percentage baseline models applied to Census 2011 total populations.
